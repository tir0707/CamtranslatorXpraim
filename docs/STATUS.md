# Проверки и оставшаяся работа

Проверено 22 октября 2026 года на Windows 10 x64 build 19045, .NET SDK 10.0.203, WebView2 Runtime 155.0.4283.62. Это **не завершённый выпуск по всем критериям ТЗ**.

## Фактические результаты

- Windows WPF: Release-сборка успешна, ноль ошибок и предупреждений. Созданы реальное главное окно и отдельное окно WebView2; наличие окон подтверждено перечнем процессов/окон. Полная визуальная проверка через computer-use не выполнена: разрешение инструмента истекло по тайм-ауту.
- WebRTC smoke: реальный HTTPS/WSS signaling, одноразовый код, два peer, H.264, 640×480, 33 декодированных кадра, WebM 107062 байта, secureContext=true. Это **синтетический canvas**, не камера iPhone. Машиночитаемый результат: `artifacts/webrtc-smoke.json`.
- Тесты транспорта: **24 проверки успешно завершены**: коды и replay/rate limit/expiry, TLS chain, HTTPS, запрет HTTP-приложения, ограничение выдачи файлов, WSS receiver, подтверждение publisher, offer/answer/ICE, bitrate command, heartbeat, отключение. Итог последнего запуска см. `artifacts/transport-tests.log`.
- Автономный Windows installer собран. Отдельная установка в профиль пользователя и удаление ещё не проверены; проверка встроенного payload не является тестом установки.
- JS-модули проходят синтаксическую проверку Node.
- Нативное iOS-приложение **успешно собрано для физического arm64 iPhone** на macOS runner GitHub Actions: [сборка 39769101268](https://github.com/tir0707/CamtranslatorXpraim/actions/runs/39769101268), commit `a50757a`. IPA сформирован и опубликован как artifact. Первичная ошибка типов RTCAudioSession исправлена по реальному журналу Xcode. IPA ещё не установлен на iPhone.
- [Облачная сборка Windows 39768823426](https://github.com/tir0707/CamtranslatorXpraim/actions/runs/39768823426) также прошла: Release, 24 проверки транспорта и создание installer.

## Реализовано исходниками, но требует проверки на устройствах

Native: захват реальных AVFoundation formats, фильтрация пяти профилей, передняя/задняя камера, ручной и автофокус, экспозиция и ISO в пределах activeFormat, WB, torch при поддержке, preview mirror, ориентация через capturer, mute, батарея и thermal throttling, остановка при уходе из foreground. Кодек H.264 через libwebrtc/VideoToolbox. Swift API подтверждены компиляцией Xcode; фактическое поведение требует iPhone.

Windows: WPF и отдельное окно видео, signaling, mDNS advertisement компьютера, ручные IP, USB candidate detection, WebRTC receive, локальные настройки, трей, добровольный автозапуск, снимок PNG, ограниченная запись WebM, папка сохранения, OBS WebSocket integration. OBS не установлен в обнаруженном стандартном расположении; тест в OBS не проводился.

## Не реализовано или не подтверждено

- Список постоянно доверенных компьютеров с устойчивой криптографической идентичностью; безопасное автоматическое переподключение publisher. Новый сеанс сейчас требует повторного подтверждения.
- Обнаружение iPhone из Windows: текущий DNS-SD работает в обратную сторону (iPhone обнаруживает ПК).
- Автоматический выбор USB и возвращение на Wi-Fi; точное определение выбранного ICE-интерфейса в UI. Показаны адреса и признаки Apple-интерфейса.
- Собственная виртуальная камера Windows 10/11 и виртуальный микрофон. OBS-интеграция не подтверждена реальным OBS/Discord.
- Выбор аудиовыхода через WPF UI, полноценный стереорежим и измерение A/V sync на устройстве. Базовое воспроизведение использует устройство Windows по умолчанию.
- Собственный видеодекодер Media Foundation: используется WebView2, конкретное GPU-ускорение требует измерений.
- Сервер обновлений, автоматическая проверка новых выпусков, подписанный Windows installer, закрепление версии Xcode/XcodeGen по подтверждённой сборке.
- Селектор кодека и ручного поворота на iPhone. Нет фиктивных кнопок для этих функций.
- Продолжительная запись без ограничения памяти — используйте OBS; встроенная WebM-запись ограничена ~256 МБ.
- Нагрузочные/длительные тесты, фактическая end-to-end задержка, поведение энергосбережения iOS, real-device TLS и mDNS, аппаратная проверка всех камер.
