# Нативное приложение iPhone с Windows и бесплатным Apple ID

## Получение IPA

1. Поместите репозиторий в свой GitHub (публикация из этой сессии не выполнялась).
2. Для бесплатной облачной сборки используйте **публичный репозиторий и стандартный macOS runner**. В private проверяйте бесплатную квоту и запрет перерасхода. Не включайте larger runners.
3. Actions → Build unsigned iPhone IPA → Run workflow. Дождитесь фактического успеха.
4. Скачайте artifact `CamtranslatorXpraim-unsigned-IPA`, извлеките IPA.
5. При ошибке сборки изучите artifact ios-build-log. Не считайте наличие workflow доказательством успешной компиляции.

Workflow использует установленный на runner Xcode, показывает его версию и SDK, генерирует проект XcodeGen и закреплённую зависимость WebRTC 154.0.0, собирает физический arm64 iPhone с `CODE_SIGNING_ALLOWED=NO`. Это упаковка `.app` в `Payload`, а не подписанный App Store export. Apple ID не вводится в GitHub и не нужен в secrets. Artifact хранится 3 дня для снижения расхода хранилища.

## AltStore Classic / AltServer

Следуйте [официальной инструкции для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). При изменении требований AltStore актуальная официальная инструкция имеет приоритет.

1. Установите бесплатные компоненты iTunes и iCloud с сайтов Apple, как требует AltStore (не смешивайте версии Microsoft Store без проверки troubleshooting AltStore).
2. Скачайте AltServer с [altstore.io](https://altstore.io/), установите и запустите.
3. Подключите iPhone Lightning-кабелем, разблокируйте, подтвердите доверие к компьютеру.
4. В iTunes включите синхронизацию по Wi-Fi, если она нужна для последующих обновлений подписи.
5. В трее AltServer выберите Install AltStore → ваш iPhone.
6. Введите Apple ID **только в официальном AltServer/AltStore**, а не в CamtranslatorXpraim, чате, workflow или файлах проекта. Нужна бесплатная учётная запись, не платная регистрация разработчика.
7. На iPhone подтвердите доверие профилю в разделе VPN и управление устройством.
8. Включите Developer Mode: Настройки → Конфиденциальность и безопасность → Режим разработчика; выполните требуемую перезагрузку и подтверждение.
9. Передайте IPA на iPhone через доступный вам доверенный файловый канал, откройте его в Files/AltStore или импортируйте кнопкой `+` в My Apps. AltStore переподпишет приложение.
10. Установите и явно доверьте локальный CA Windows по [инструкции запуска](QUICKSTART.md).
11. Откройте CamtranslatorXpraim, укажите адрес ПК, код и подтвердите соединение в Windows.

Подпись бесплатного Apple ID обычно истекает через 7 дней; приложение нужно обновлять/refresh через AltStore при доступном AltServer. Одновременно до трёх активных sideload-приложений; AltStore занимает один слот. Ограничения App IDs также могут мешать повторной установке. Установка конкретного IPA на iPhone XR пока не проверена.

Если нет возможности собрать/подписать нативное приложение, используйте **Safari-клиент через HTTPS** из QUICKSTART. Он не требует Apple ID или еженедельной подписи, но имеет ограничения браузерного управления камерой. Это резервный клиент; исходники native остаются в `apps/ios`.
