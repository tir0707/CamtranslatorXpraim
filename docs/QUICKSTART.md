# Запуск без оплаты

## 1. Windows

1. Запустите `CamtranslatorXpraim-Setup.exe`. Он устанавливает приложение только текущему пользователю, без обязательной учётной записи.
2. Откройте CamtranslatorXpraim из меню «Пуск» (или `dist/app/CamtranslatorXpraim.exe` из portable-сборки).
3. Если WebView2 Runtime отсутствует, установите бесплатный Evergreen Runtime с [Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). .NET входит в установщик.
4. Должны открыться управление и отдельное окно «CamtranslatorXpraim — Видео».
5. Разрешите приложению входящие соединения только в вашей частной сети через стандартный запрос Windows, если он появится. Нужны TCP 47990/47991, mDNS UDP 5353 и UDP WebRTC-процесса WebView2. Автоматически отключать брандмауэр не требуется.
6. Подключите iPhone и компьютер к одной домашней сети; отключите изоляцию клиентов роутера/гостевой Wi-Fi. VPN может мешать прямым локальным ICE-соединениям.

## 2. Доверенный HTTPS на iPhone

1. В Windows раскройте «Подключение, сохранение и сертификат». Запишите SHA-256 CA и HTTPS-адрес активного сетевого интерфейса.
2. На iPhone в Safari откройте указанный в Windows адрес `http://IP-ПК:47991/ca.cer`. Этот HTTP-порт отдаёт только публичный сертификат, камеры на нём нет.
3. До установки проверьте подлинность сертификата: сравните SHA-256 на независимом устройстве/доверенным инструментом с отпечатком в окне Windows. HTTP-загрузка сама по себе подлинность не доказывает. При сомнении передайте `.cer` по доверенному каналу вместо HTTP.
4. Установите загруженный профиль в Настройки → Основные → VPN и управление устройством.
5. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите полное доверие **CamtranslatorXpraim Local CA**. Это действие пользователь выполняет сам.
6. Откройте `https://IP-ПК:47990`. Не продолжайте через предупреждение TLS. Если адрес изменился, перезапустите приложение Windows: новый сертификат сервера должен содержать новый IP; CA остаётся прежним.

Официальные сведения Apple: [доверие вручную установленным сертификатам](https://support.apple.com/en-us/102390). Сертификат нужен и нативному приложению. Windows-предпросмотр доверяет только точному сертификату своего процесса на loopback и не требует установки CA в хранилище Windows.

## 3. Первый видеосеанс через Safari

1. Введите текущий шестизначный код из Windows. Он действует 5 минут; кнопка «Обновить код» выдаёт новый.
2. Выберите 720p/30. Микрофон по умолчанию выключен.
3. Нажмите «Подключить камеру» и разрешите камеру. При запросе микрофона убедитесь, что вы включили его сами.
4. Подтвердите запрос устройства на компьютере. После этого видео должно появиться в отдельном окне.
5. Safari → Поделиться → На экран «Домой» добавит ярлык. Приложение всё равно должно оставаться открытым, экран — разблокированным.
6. Для остановки нажмите «Остановить» на iPhone или «Отключить iPhone» на ПК. При разрыве связи новый сеанс требует нового кода; автоматического повторного доступа к камере нет.

Реальные размеры/FPS захвата показаны на iPhone, размеры/FPS приёма — на Windows. Safari может отклонить конкретный режим. Опции браузерного клиента — запросы ограничений, не гарантированный список возможностей XR. Нативный клиент фильтрует режимы по AVFoundation.

## 4. OBS → Discord, Zoom, браузеры

1. Установите [OBS Studio](https://obsproject.com/download) бесплатно.
2. Откройте окно видео CamtranslatorXpraim и оставьте его развёрнутым или обычным, не минимизируйте: захват свёрнутого окна может остановиться.
3. OBS → Сервис → Настройки сервера WebSocket → включите сервер, порт 4455, включите аутентификацию.
4. Введите пароль OBS в CamtranslatorXpraim и нажмите «Настроить OBS и включить камеру». Пароль не сохраняется.
5. Будет создана/обновлена сцена **CamtranslatorXpraim** с источником захвата окна. Она станет текущей сценой OBS. Проверьте изображение в OBS, затем включение Virtual Camera.
6. В Discord/Zoom выберите **OBS Virtual Camera**. В браузере выберите её как видеоустройство и разрешите доступ. Проверьте изображение в каждом приложении отдельно.
7. Если автоматическая настройка не сработала: создайте источник «Захват окна», выберите «CamtranslatorXpraim — Видео», включите захват клиентской области, подгоните источник под сцену, нажмите «Запустить виртуальную камеру».

OBS Virtual Camera передаёт видео. Она **не** является виртуальным микрофоном. Для голоса в сторонних программах пока выберите микрофон ПК. Звук iPhone доступен в предпросмотре и записи WebM; маршрутизация в микрофон требует отдельного проверенного аудиоустройства.

## 5. USB

Подключите Lightning, подтвердите доверие на iPhone, установите Apple Devices/iTunes согласно инструкции Apple, включите «Режим модема», если доступен. Нажмите «Обновить адреса и проверить USB». При наличии Apple-интерфейса откройте его HTTPS-адрес на iPhone. После появления нового интерфейса перезапустите Windows-приложение для SAN сертификата.

Метка «возможный USB» не доказывает путь WebRTC. Для проверки отключите Wi-Fi и убедитесь, что видео продолжает поступать и растут счётчики именно Apple-интерфейса. При недоступном режиме модема используйте Wi-Fi; наличие кабеля само по себе не создаёт USB-видеоканал.

## Ошибки

- Пустой preview: проверьте разрешение камеры, подтверждение Windows, локальную сеть и брандмауэр; начните с 480p/30.
- TLS: установите именно CA с данного компьютера и полное доверие; проверьте дату и IP. Не используйте отключение проверки сертификата.
- Код отклонён: обновите его; после пяти неудачных попыток подождите пять минут.
- Порт занят: закройте вторую копию приложения. Не запускайте одновременно две версии.
- Чёрное видео в OBS: не сворачивайте окно видео, попробуйте другой метод захвата в свойствах OBS.
- FPS/битрейт могут отличаться от выбранного профиля; RTT не является полной задержкой.
- Запись ограничена примерно 256 МБ на фрагмент; для длинной записи используйте OBS.
