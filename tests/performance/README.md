# Измерение производительности на реальном устройстве

Автотест синтетического видео проверяет кодирование/декодирование и связность, а не производительность iPhone XR.

Для каждого режима 480p/30, 720p/30, 1080p/30, 720p/60, 1080p/60:

1. Записать модель iPhone, iOS, объектив, выбранный AVFoundation format, Windows/GPU/драйвер, WebView2, интерфейс и сеть.
2. Запустить 10 минут, затем 60 минут: FPS приёма, dropped frames, Mbps, RTT, jitter buffer, decode time, загрузка CPU/GPU, температура и батарея.
3. Задержку **камера → экран** измерять съёмкой общего миллисекундного таймера: реальный таймер и его изображение на мониторе должны попасть на одну фотографию внешней камерой. Сделать >=30 замеров, указать p50/p95 и ошибку метода. RTT/2 не использовать как замену.
4. Повторить при искусственной загрузке Wi-Fi, обрыве сети, извлечении USB и переключении камер. Проверить, что старые кадры не накапливаются.
5. Отдельно проверить Win10/Win11, OBS, Discord, Zoom, Windows Camera и getUserMedia в браузере. Записать реальный список обнаруженных устройств. Отсутствующие результаты не отмечать успешными.

Цель <150 мс — исследовательская, не гарантия. Протокол результатов: `docs/STATUS.md`.
